# Project Authorship

## Musa Divarcı

**Creator, Project Lead and Software Engineer — Aegis**

Aegis was conceived, architected and developed as an independent software engineering project by **Musa Divarcı**.

The project explores durable memory architectures for AI-assisted software, including persistent knowledge, decision records, semantic retrieval, retrieval-augmented generation (RAG), vector search, knowledge relationships and traceable reasoning.

### Technical responsibilities

- Product concept and system architecture
- Domain and data architecture
- AI memory and retrieval design
- RAG architecture
- PostgreSQL / pgvector persistence model
- Next.js and TypeScript application architecture
- Provider-independent embedding and reasoning contracts
- Traceability and architectural decision records
